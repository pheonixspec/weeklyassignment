# weeklyassignment

This repository is a collection of Java practice work organized by week. Each folder shows a different stage of learning, from basic problem solving to larger programs that use methods, arrays, strings, and exception handling.

## Folder Summary

- `week1n2`: basic Java practice with input, output, loops, conditions, and simple problem solving.
- `week3n4`: more practice with structured methods and larger logic-based programs.
- `week5n6`: string and array exercises with more focus on clean program flow.
- `week7n8`: math-heavy and utility-style programs like calendars, scorecards, conversions, and number checks.
- `week9n10`: advanced string handling, exception examples, text processing, games, grades, and card-deck logic.

## What I Learned

These questions helped me get comfortable with breaking a problem into smaller methods, using loops and arrays correctly, and handling user input without overcomplicating the code. I also learned how useful Java’s built-in methods are when comparing my own logic against the standard way of doing things.
