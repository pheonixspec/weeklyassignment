# Week 9/10 Practice Programs

## Level 1 Practice Programs

1. Compare two strings using a user-defined `charAt()`-based method and verify the result against `String.equals()`.
2. Create a substring using `charAt()`, then compare it with the result of `substring()`.
3. Return all characters in a string using a custom method and compare the output with `toCharArray()`.
4. Demonstrate `NullPointerException` by calling a string method on a `null` reference, then handle it with `try-catch`.
5. Demonstrate `StringIndexOutOfBoundsException` by calling `charAt()` with an invalid index, then handle it with `try-catch`.
6. Demonstrate `IllegalArgumentException` by calling `substring()` with an invalid range, then handle it with `try-catch`.
7. Demonstrate `NumberFormatException` by using `Integer.parseInt()` on non-numeric text, then handle it with `try-catch`.
8. Demonstrate `ArrayIndexOutOfBoundsException` by accessing an invalid array index, then handle it with `try-catch`.
9. Convert complete text to uppercase using `charAt()` logic and compare it with `String.toUpperCase()`.
10. Convert complete text to lowercase using `charAt()` logic and compare it with `String.toLowerCase()`.

## Level 2 Practice Programs

1. Find the length of a string without using `length()` and compare it with the built-in method.
2. Split text into words using `charAt()`, compare it with `split()`, and display the result.
3. Split text into words and return each word with its length in a 2D array.
4. Split text into words and find the shortest and longest words.
5. Count vowels and consonants in a string and display the totals.
6. Classify each character in a string as vowel, consonant, or not a letter.
7. Trim leading and trailing spaces using `charAt()` and compare it with `trim()`.
8. Take ages of 10 students and determine whether each student can vote.
9. Simulate Rock-Paper-Scissors for multiple games and display win statistics and percentages.
10. Generate student scorecards for Physics, Chemistry, and Maths, then compute total, average, percentage, and grade.

## Level 3 Practice Programs

1. Calculate BMI for 10 people and display height, weight, BMI, and status.
2. Find unique characters in a string using `charAt()`.
3. Find the first non-repeating character in a string.
4. Find the frequency of characters in a string using ASCII indexing.
5. Find the frequency of characters using unique characters.
6. Find the frequency of characters using nested loops.
7. Check whether a text is a palindrome using three different approaches.
8. Check whether two texts are anagrams.
9. Display a calendar for a given month and year.
10. Create, shuffle, and distribute a deck of cards to players.
